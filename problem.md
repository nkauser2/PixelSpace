# Problem 
Students who want to pursue or are interested in digital art may not have as much access to digital art resources or digital/graphic art tools. The tools which are available may be overwhelming (too professional) for beginners to understand while other softwares might be too basic. Beginners might also have limited opportunities to experiment with colors or tools at that entry level. Students need an easily accesible yet modern way to learn and practice creative skills/tools and make digital artwork without having to learn it professionally.

# Initial requirements

**R1:**
The program must display an interactive interface/canvas where users can create their digital artwork. 

**R2:**
The program must provide an original color palette and custom color selecting option. 

**R3**
The program must provide a brush to draw freely/free-handed strokes on the canvas with the selected color. 

**R4**
The program must provide an eraser tool to remove strokes or marks that were already drawn.

**R5**
The program must allow users to undo or redo drawing strokes or actions.  

**R6**
The program must allow users to save artwork and reopen it with previous work saved. 

**R7**
The program must allow and provide users with ready-made drawings or coloring templates.

**R8**
The program must allow users the option to clear the canvas completely if they like. 

# Round 2 requirements

**R9**
The program must show the 5 most recently picked colors, with each color shown only once, and clicking on one of them must select it again as the current color. 

**R10**
The program must allow the user to rename a saved artwork or drawing without losing it. If the new name is already used by another piece of saved artwork, the program must ask the user to confirm it before replacing it. 

# Round 3 requirements

**R7** 
The program must provide a set of shapes, letters, numbers that students can place on the canvas. These can be colorable. This replaces the ready-made drawings and coloring templates.

**R11**
The program must include a button to flip (mirror horizontally or vertically) and rotate (90 degrees per click) the shapes/letters/numbers.

# Round 4 requirements 

**R12** 
The background of the program must be light pastel gradient colors. It must go from lavender to soft pink to baby blue to mint green, replacing the white background. It must cover whole page except for canvas and surrounding color palette. 

# Round 5 requirements

**R13**
The program must have an icon of a dark purple deer with pink antlers on the top right corner of the canvas, that serves as the icon for the browser tab.

**R14** 
The program must have the icon of the deer be half its size on narrow (under 600 pixels) screens. 

# Round 6 requirements

**R15** 
The program must have a gallery view (that is accessed via a button) that shows all saved artworks as small previews, so students can open one without opening each file. Five artworks per row, most latest first.

# Round 7 requirements

**R16**
The program must have a "Welcome to PixelSpace" message at the top center of the page, written in cursive.
